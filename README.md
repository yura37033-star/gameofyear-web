# Архів версій демо

Старіші версії гри, що вийшли з гілки `Working_Demo`. Це файли для перегляду й порівняння, не для публікації.

| Папка | Версія | Походження |
| --- | --- | --- |
| `demo4/` | Демо 4: поле 10 × 16, чотири кольори, очищення будь-якого повного ряду | проєкт, коміт `a8e6fb9` |
| `demo5-first/` | Демо 5, перша публікація: 10 × 16, два кольори, два повороти | публікація `966d97d` гілки `main` цього репозиторію |
| `demo5-10x20/` | Демо 5: поле 10 × 20, два кольори, поворот з підйомом | публікація `9ce994e` гілки `main` цього репозиторію |

Кожна папка самодостатня: відкрийте її `index.html` через локальний сервер.
